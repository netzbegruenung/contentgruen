# Sicherheit / Security

## Deutsch

Bitte melde Sicherheitslücken **nicht** als öffentliches Issue, nicht in Pull Requests und nicht
in Diskussionen.

Nutze stattdessen die private Meldung über GitHub: Reiter **Security** → **Report a
vulnerability** (Private Vulnerability Reporting). Die Meldung sehen nur die Maintainer.

Hilfreich sind: betroffene Komponente (Frontend, BFF, Backend), Schritte zum Nachvollziehen und
die mögliche Auswirkung. Wir bestätigen den Eingang und melden uns, sobald wir die Lücke
eingeschätzt haben. Bitte veröffentliche Details erst, wenn eine Korrektur ausgeliefert ist.

## English

Please do **not** report security vulnerabilities through public issues, pull requests or
discussions.

Use GitHub's private reporting instead: **Security** tab → **Report a vulnerability** (Private
Vulnerability Reporting). Only the maintainers can see the report.

Helpful details: the affected component (frontend, BFF, backend), steps to reproduce and the
possible impact. We will acknowledge your report and get back to you once we have assessed it.
Please do not disclose details publicly until a fix has been released.
