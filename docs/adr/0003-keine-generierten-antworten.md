# Gut gesagt generiert keine Antworten, KI hilft nur beim Erfassen

Gut gesagt ist ein kuratierter Austausch von Argumenten, die Menschen geprüft haben, kein Generator. KI darf beim Erfassen helfen (etwa eine Bildbeschreibung vorschlagen), erzeugt aber keine Inhalte, die anderen als Antwort gezeigt werden. Grund ist das Reputationsrisiko: Eine Antwort, die einen Fakt erfindet oder eine Position falsch zuschreibt, fällt auf die Partei zurück. Generierte Antworten kommen frühestens als letzte Stufe und nur als Entwurf, den ein Mensch bearbeitet und abschickt.

## Consequences

Jede KI-Funktion, die Daten an einen externen Anbieter schickt, braucht vorher eine Erweiterung der Datenschutzerklärung; ohne gesetzten Schlüssel ist die Bildbeschreibung abgeschaltet.
