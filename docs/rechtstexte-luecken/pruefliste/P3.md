# P3

- **Stelle:** **Löschung als Anonymisierung**
- **Was zu prüfen ist:** Beiträge werden bei Kontolöschung nicht gelöscht, sondern die Kennung durch einen Platzhalter ersetzt. Ob das Art. 17 DSGVO in dieser Konstellation genügt — CC0-Lizenz, Bestandscharakter, Verweise anderer Beiträge —, ist eine Wertung. Der Text beschreibt das Verfahren offen, einschließlich der Grenze, dass CC0-Freigaben nicht zurückgeholt werden können
