# P8

- **Stelle:** **Rechtsgrundlage der Bild-Einbindung**
- **Was zu prüfen ist:** Der Abruf fremder Bild-Hosts durch den Browser der Besuchenden ist auf lit. f gestützt. Ob das trägt oder ob es einen Zwischenschritt braucht (Proxy, Vorschaubild, Klick-zum-Laden), ist zu prüfen — ein Proxy wäre auch die technische Lösung. **Entschieden (29.10.2026), gebaut mit #447:** Klick-zum-Laden, kein Proxy (kein Urheberrechtsrisiko). Ohne Klick geht keine Anfrage an den fremden Server. Ob lit. f für den Abruf nach dem Klick trägt, bleibt zu prüfen **Nachtrag (juristische Vorprüfung vom 12.11.2026):** Der Satz „Diesen Abruf richtet dein Browser aus, nicht wir“ widersprach EuGH C-40/17 (Fashion ID): Wer ein Element einbindet, das den Browser Daten an einen Dritten übermitteln lässt, ist dafür mitverantwortlich. Die Datenschutzerklärung (Abschnitt „Keine Übermittlung außerhalb der EU“) nennt jetzt die Mitverantwortung für das Einbinden und die Übermittlung der IP-Adresse; was der fremde Server danach tut, verantwortet sein Betreiber. Offen bleibt, ob der Abruf von einem Server außerhalb der EU eine Übermittlung nach Kapitel V DSGVO ist.
