# P7

- **Stelle:** **Protokolldateien ohne feste Frist**
- **Was zu prüfen ist:** Für die Anwendungsprotokolle gibt es derzeit keine Frist; der Text sagt das und kündigt eine Volumenbegrenzung an. **Diese Stelle ist anzupassen, sobald der `logging:`-Block im Betrieb ausgerollt ist**, dann kann eine Zahl genannt werden. Ziel seit #422: höchstens 14 Tage (`docs/LOESCHKONZEPT.md`, Logs, Fristen)
